# رصد | نسخة PWA تمهيدية

هذه نسخة قابلة للاستضافة والتثبيت على الأجهزة، لكنها **بوابة** تفتح رابط Google Apps Script المنشور في المتصفح؛ وليست تحويلًا مكتملًا للواجهة أو نظامًا مستقلًا متصلًا بقاعدة البيانات. لا تحفظ بيانات طلاب أو رموز دخول، ولا تغيّر ملفي Index.html وCode.gs ولا Google Sheets.

## طريقة التجربة
1. ارفع محتويات المجلد كما هي إلى استضافة HTTPS ثابتة مثل GitHub Pages أو Cloudflare Pages، مع مراعاة سياسة المدرسة للهوية والنشر.
2. افتح رابط الاستضافة على Android في Chrome، ثم اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
3. على iPhone افتح رابط الاستضافة في Safari، واختر مشاركة ثم «إضافة إلى الشاشة الرئيسية».
4. اضغط «فتح نظام الغياب والهروب»؛ يفتح النظام الرسمي في المتصفح الخارجي، وقد يتطلب تسجيل الدخول حسب صلاحيات Google.

## قبل نسخة PWA الكاملة
الواجهة الحالية تستخدم google.script.run داخل Google Apps Script، لذلك نقلها إلى نطاق خارجي كما هي لن يعمل. يلزم تصميم واجهة مستقلة وواجهة API آمنة بمصادقة حقيقية وصلاحيات محددة للمعلمين والوكيل، دون وضع رموز دخول أو بيانات الطلاب في ملفات عامة. لا تستخدم CORS مفتوحًا أو رابط Apps Script منشورًا بصلاحيات كتابة دون ضوابط. لا يُخزّن عامل الخدمة بيانات حساسة؛ هو يخزن ملفات البوابة الثابتة فقط.

**مهم:** هذه الملفات لم تُرفع أو تُنشر؛ رابط النظام الحالي لم يتغير.
